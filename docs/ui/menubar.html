메뉴바와 알림

메뉴와 알림은 macOS가 그린다. 앱은 아이콘, 메뉴 항목, 알림 문구만 정한다.

메뉴바 아이콘

단색 template 이미지라 라이트와 다크 메뉴바에 자동으로 맞는다. 상태는 모양으로 구분하고, 색은 오류 점 하나만 쓴다.

평상시수집 완료, 대기
수집 중흐려지고 호가 돈다. 움직임 줄이기 설정이면 호만 멈춰 있다
오류빨간 점, 이유는 메뉴 첫 줄에
일시정지흐린 틀 안에 정지 표시
