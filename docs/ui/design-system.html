context-holder 디자인 시스템

읽는 화면은 신문, 다루는 화면은 도구. 종이와 잉크 두 가지 바탕에 의미 색 두 개(오늘, 결정)만 얹는다. 상태 색은 상태를 알릴 때만 쓰고, 항상 아이콘이나 문구와 같이 쓴다.

원칙

  • 읽기와 다루기를 나눈다Today와 Decisions는 크고 굵은 제목과 넓은 여백. Search, Inbox, Sources는 산세리프와 촘촘한 리스트.
  • 색은 뜻이 있을 때만붉은 잉크는 오늘과 영상, 청록은 결정 사례. 그 외 강조는 굵기와 크기로 한다.
  • 화면마다 주된 행동 하나Today는 읽기, Inbox는 분류, Decisions는 비교. 버튼 강조는 그 행동 하나에만 준다.
